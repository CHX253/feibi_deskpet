# 菲比桌宠

一款基于 Python 与 PySide6 开发的 Windows 桌面宠物。

## 下载菲比

### Windows 64位版本

[点击进入最新版本下载页面b.com/CHX253/feibi_deskpet/releases/latest

进入页面后，在 **Assets** 区域下载：

`PhoebePet_Windows_x64.zip`

> 请完整解压ZIP，然后双击 `PhoebePet.exe`。  
> 不要只把 `PhoebePet.exe` 单独移动到其他位置。

## 主要功能

- 自由活动、飞行与穿屏
- 摸头和下半部分互动
- 鼠标拖动拎起动作
- 喝水与久坐提醒
- W/S健康留言
- 入场分时问候
- 退场告别动画
- 专注计时、快捷便签和记事本
- 桌宠尺寸、透明度和始终置顶
- 本体与托盘菜单功能分类
- 开机自启动

## 使用方法

1. 下载 `PhoebePet_Windows_x64.zip`
2. 右键压缩包，选择“全部解压”
3. 打开解压后的 `PhoebePet` 文件夹
4. 双击 `PhoebePet.exe`
5. 退出时，右键菲比或托盘图标，选择“退出桌宠”

## 系统要求

- Windows 10 或 Windows 11
- 64位系统
- 无需安装Python
